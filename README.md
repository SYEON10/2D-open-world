# 2D-open-world

Godot 4.7.2 기반 프로젝트입니다. 현재는 WASD로 움직이는 3D 큐브 예제와 AI 개발용 Godot MCP 연결이 준비되어 있습니다.

## 시작하기

1. Godot 4.7.2에서 이 폴더의 `project.godot`을 엽니다.
2. 메인 씬을 실행하고 WASD로 큐브를 움직입니다.
3. PowerShell에서 `GODOT_BIN`을 Godot 콘솔 실행 파일 경로로 설정한 뒤 `./scripts/check.ps1`을 실행해 리소스와 이동 동작을 확인합니다.
