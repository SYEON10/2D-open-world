# Task 5 — GitHub 저장소 연결

## 목표
현재 프로젝트의 로컬 `main` 이력을 `https://github.com/SYEON10/2D-open-world.git`에서 관리한다.

## 세부 작업
- [x] 원격 `main`의 기존 이력과 파일을 확인한다.
- [x] `origin`을 지정된 GitHub 저장소로 등록한다.
- [x] 원격의 README 초기 커밋을 덮어쓰지 않고 로컬 이력에 병합한다.
- [x] 프로젝트 사용법과 문서 진입점을 README에 기록한다.
- [x] 로컬 `main`을 `origin/main`에 올리고 추적 브랜치로 설정한다.
- [x] 원격 커밋과 로컬 브랜치 상태를 확인한다.

## 완료 기준
`origin/main`에 프로젝트 파일과 기존 README 이력이 모두 있고, 로컬 `main`이 원격을 추적한다. 강제 푸시는 사용하지 않는다.
