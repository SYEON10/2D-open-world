# Task 2 — Godot MCP 연결과 이동 예제

## 목표
씬 읽기·수정과 바이너리 리소스 정보 읽기를 지원하는 오픈소스 MCP를 설치하고, 큐브 이동 씬을 만든다.

## 세부 작업
- [x] 공개 MCP 후보의 씬 편집, 상태 조회, 바이너리 리소스 조회, 설치 요건을 비교한다.
- [x] 선택한 MCP의 Godot 애드온과 Codex 서버를 설치한다.
- [x] Godot에서 애드온을 활성화하고 도구 연결을 확인한다.
- [x] 큐브, 바닥, 카메라, 조명이 있는 씬과 WASD 이동 스크립트를 만든다.
- [x] MCP로 씬을 읽고 노드 또는 속성을 실제 수정한 뒤 다시 읽는다.
- [x] MCP로 바이너리 리소스 정보를 읽는다.
- [x] MCP 기능과 한계를 `Docs/GODOT_MCP.md`에 기록한다.
- [x] Godot에서 가져오기·구문 검사·실행을 확인한다.

## 완료 기준
MCP 도구 호출로 씬 조회·편집과 바이너리 에셋 정보 조회가 확인되고, 큐브가 WASD로 움직인다.
